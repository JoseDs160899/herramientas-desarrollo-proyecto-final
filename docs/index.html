REGISTRAU
02 / 12
01 · Introducción

Un solo sistema.
Información centralizada.

RegistraU es una aplicación web orientada al registro y gestión básica de estudiantes o postulantes. El proyecto se mantiene sobre un mismo código, repositorio y documentación durante el semestre.

📋

Registro

Crear fichas con información personal y de contacto.

🔎

Consulta

Localizar y consultar fichas almacenadas en el sistema.

🔄

Actualización

Modificar información existente sin generar duplicados.

02 · Planteamiento del problema

La información está dispersa.

En procesos de admisión de pequeña escala, los datos pueden quedar distribuidos entre formularios, hojas de cálculo y mensajes.

! Campos incompletos
! Errores de digitación
! Dificultad para localizar fichas
