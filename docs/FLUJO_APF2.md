# Flujo colaborativo APF2 - RegistraU

1. Cada integrante crea una rama desde main.
2. Implementa y verifica su tarea asignada.
3. Registra commits descriptivos.
4. Publica su rama en GitHub.
5. Crea un Pull Request hacia main.
6. Solicita revisión de otro integrante.
7. Atiende los comentarios del revisor.
8. Integra el PR cuando esté aprobado.
9. Actualiza el tablero de GitHub Projects.
